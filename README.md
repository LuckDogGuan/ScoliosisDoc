## 目录与资料性质

- `调试/工具/`：可复用的 Windows 调试和验证工具，各工具有独立依赖及使用条件。
- `调试/软件架构/`、`调试/doc/`、`docs/adr/`：设计、协议和决策。计划项不等于已经实现。
- `调试/记录/`：按日期保留的现场结果、报告和历史探针；不能直接当成当前版本状态。
- `调试/基础信息/`、`调试/配置/`：本项目设备信息和配置快照；使用前核对自己的设备、网络和版本。
- `调试/声音/`、`调试/图像/`：项目提示音及图像证据。
- SDK、虚拟机、系统镜像、第三方软件和示例大包保留在本机，由 `.gitignore` 排除；通过资料来源页重新获取。

现有历史中的源码摘录、对照 ZIP 和板端备份属于当时的审计材料，保留其历史身份。后续开发及正式发布仍遵循三仓库所有权。

## 使用记录的原则

日期报告描述的是当时的设备与版本；修改前先核对当前权威源码。构建成功、静态检查、实板出图、实体按键、冷启动和现场验收分别看证据。旧记录中的绝对路径是原机器位置；本仓库新导航均使用相对链接。

第三方材料的原版权、许可及具体来源见 [资料来源与下载](docs/资料来源与下载.md)。本仓库未统一声明开源许可证。
