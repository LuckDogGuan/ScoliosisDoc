# 语音提示音多风格试听与选型说明

本目录针对 **Luckfox Pico Zero（RV1106）校园脊柱侧弯筛查设备** 制作了 4 组不同音色与听感风格的提示音，全部采用标准的 **16 kHz、单声道（Mono）、16-bit PCM WAV** 编码格式，可直接在电脑上试听，也可直接推送到下位机板端 `/userdata/sounds/` 播放。

## 三、快速推送到板端测试

选定满意的风格后，可以使用 ADB 直接将该风格的全部文件覆盖推送到 Luckfox Pico Zero 板上进行真机扬声器试听：

### 1. 推送「1_晓晓_专业医用女声」（默认推荐）
```powershell
& "D:\code\Scoliosis\Luckfox\调试\工具\adb.ps1" push "D:\code\Scoliosis\Luckfox\调试\语音风格试听\1_晓晓_专业医用女声\*" /userdata/sounds/
```

### 2. 推送「2_晓伊_亲和校园女声」（亲和推荐）
```powershell
& "D:\code\Scoliosis\Luckfox\调试\工具\adb.ps1" push "D:\code\Scoliosis\Luckfox\调试\语音风格试听\2_晓伊_亲和校园女声\*" /userdata/sounds/
```

### 3. 板端测试播放命令
登录板端终端后，执行即可试听喇叭效果：
```sh
# 测试播放拍摄完成
tinyplay /userdata/sounds/capture_done.wav
```
