## 板端命令

安装后的程序和 helper 位于 /opt/instrument/bin；helper 与程序同目录。
临时验证使用 /tmp/instrument-light-test-331，同一入口。

~~~sh
/opt/instrument/bin/instrument_app --light-test center off --ground-verified
/opt/instrument/bin/instrument_app --light-test center on --ground-verified
/opt/instrument/bin/instrument_app --light-test center slow --ground-verified
/opt/instrument/bin/instrument_app --light-test center fast --ground-verified
/opt/instrument/bin/instrument_app --light-test center breathe --ground-verified
/opt/instrument/bin/instrument_app --light-test backlight on
/opt/instrument/bin/instrument_app --light-test backlight off
~~~

默认30秒，--seconds 1..300 可缩短。默认高电平有效；若模块控制逻辑反向，核验后使用 --active-low，仍然在结束时关闭输出。

- 慢闪：亮、灭各1秒；快闪：亮、灭各0.125秒。
- 呼吸：3秒线性上升/下降；PWM周期1,000,000ns（1kHz），15ms更新占空比。
- 复用示例 gpio.c/pwm.c 的 Linux sysfs；修正示例无限循环、PWM编号固定和缺少清理的问题。
- light_pwm.sh 复用板上 luckfox-config 的 configfs overlay 机制，读取当前 PWM2_M0 phandle，仅启用 /pwm@ff350020；不修改 /etc/luckfox.cfg、不写开机配置。
- Rockchip PWM 要先设置 period，再设置 duty/enable。按设备物理路径 ff350020.pwm 找 pwmchip，不能固定成 pwmchip0/10。
- Linux flock 拒绝并发测试；已有 GPIO/PWM占用、PWM不可用、参数错误均明确报错；没有软件 PWM 替代。
- 正常超时、SIGINT、SIGTERM、SIGHUP、可处理的 I/O错误均执行灭灯/取消导出/撤销 overlay。SIGKILL、掉电、内核异常无法执行用户态清理；异常时重启复位，不承诺这些场景自动灭灯。
- 返回0为软件调用和清理成功；2为参数/身份/回路核验错误；1为硬件接口失败；信号退出为128+信号。

## Python中间层

入口：Windows 调试/工具/Python中间层/light_test.py。
复用现有 Paramiko、SSH known_hosts 和板端入口，不新增网络协议、后台服务或 Flutter功能。
SSH主机密钥、板序列号、config.json设备ID、active-v3.json和writing目录都必须通过检查；未知主机密钥拒绝自动信任，密码只交互输入或标准输入，不写日志。

~~~powershell
python 调试/工具/Python中间层/light_test.py --address 实际板IP --serial 41eda5f2c5b00de1 --device-id CAM-41eda5f2c5b00de1 backlight on
python 调试/工具/Python中间层/light_test.py --address 实际板IP --serial 41eda5f2c5b00de1 --device-id CAM-41eda5f2c5b00de1 --ground-verified center breathe
~~~

现场没有Wi-Fi地址，本次真实SSH验证走既有ADB转发：

~~~powershell
adb -s 41eda5f2c5b00de1 forward tcp:12222 tcp:22
python 调试/工具/Python中间层/light_test.py --address 127.0.0.1 --port 12222 --host-key-name 192.168.101.3 --serial 41eda5f2c5b00de1 --device-id CAM-41eda5f2c5b00de1 --app /tmp/instrument-light-test-331/instrument_app backlight on
~~~

host-key-name 是旧 known_hosts 中的已核对密钥别名，不是当前板IP。实板以序列号与设备ID再次核对。本次板的公开SSH密钥也通过指定ADB序列号读取公钥交叉核对。
日志默认绝对路径：D:/code/Scoliosis/Luckfox/调试/记录/light-test-20261007/python-light.jsonl。
Python窗口被中断或SSH连接丢失时，远端仍有自己的30秒/指定时限，最长300秒；不保证客户端断开即刻灭灯。
