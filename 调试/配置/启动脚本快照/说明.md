# `/RkLunch.sh` 快照

这些文件原来放在 Luckfox 仓库根目录，是调试音量和开机进程时从板子拉下来的副本。现行对照用 [方案/RkLunch.sh.board](../方案/RkLunch.sh.board)：音量 30 的硬编码已注释，末尾有 `mkdir -p /video0 /video1 /video2`。业务进程由 [方案/S80instrument](../方案/S80instrument) 启动 `/opt/instrument/bin/instrument_app`，不要再从这些快照里找 `instrument_app`。

| 文件 | 和现行板脚本的差别 |
| --- | --- |
| `RkLunch.sh.before_audio_change` | 还没写死音量 30，启动的是 `/usr/bin/camera_test` |
| `RkLunch.sh.audio30` | 音量写成 30，启动 `camera_test`，并且每次覆盖 `/userdata/rkipc.ini` |
| `RkLunch.sh.audio30_camera` | 音量 30，启动的已是 `/oem/usr/bin/rkipc` |
| `RkLunch.sh.final` | 音量 30，启动 rkipc，ini 只在缺失时复制 |

2026-09-29 实板上曾有两处同时拉起 `instrument_app`（本脚本尾部和 `S80instrument`）。那次修复后，重复启动行从板上的 `/RkLunch.sh` 去掉。过程见 [连接重连与容量修复](../../记录/连接重连与容量修复_2026-09-29.md)。
