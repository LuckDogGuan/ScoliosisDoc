# 单设备筛查：上位机实施契约

## 已确认的产品规则

- Windows Flutter；一台电脑只使用一台当前设备。点击“断开并解除配对”立即停止下发新拍摄命令，既有录制与上传安全收尾。离线解除须显示“设备待确认”；解除后保留历史设备和所有拍摄记录。
- 出生日期选择器使用 `zh_CN`。信号质量是 RSSI 换算的参考百分比，仍展示 dBm 原值；存储与内存展示可用量、总量和百分比。没有主电池时显示“未安装”。过期遥测显示灰色及上报时间。
- 顺序模式始终展示学生既有拍摄次数与历史；“跳过”标记跨天生效，直到人工清除，操作和原因保留历史。已拍摄学生允许明确重拍。
- 录像完成且板端文件进入待传目录即可拍下一人。界面分别展示当前录制与后台上传队列，不用固定秒数猜测上传结果。
- Excel 只用于名单导入、模板及导出，SQLite 是学校、班级、学生、筛查、拍摄、设备、跳过与角度采样的唯一业务状态源。

## 数据与迁移

数据库放在既有 `data` 根目录；视频保留为文件，数据库保存相对路径、字节数和 SHA-256，不放视频 BLOB。表包括 `schools`、`classes`、`students`、`import_batches`、`screenings`、`captures`、`skip_events`、`devices`、`angle_samples`。学生有稳定 ID，同校学号唯一；一次拍摄一个 `capture_id`，重拍新增记录。每五个解码帧选一帧，采样保留帧序号、真实 PTS、带符号的尺角度或失败原因、模型版本。曲线名称为“测量尺角度随时间”，不称脊柱曲线或 Cobb 角。

首次迁移读取原 `名单/*.csv`、`筛查/*/{名单.csv,记录.csv,状态.json}`、`设备.json`；先备份和校验，按自然键及 `capture_id` 幂等入库，记录迁移版本；成功前保留原件。视频文件名改为不含姓名、学号的 `capture_id.mp4`，更名失败保留原路径并在界面列为待处理，不能让数据库指向不存在的文件。导出或共享前检查画面、文件名与元数据中是否出现个人标识。

## 通信与状态

发现、报到、配对请求、设备确认、在线、离线、主动解除是不同事实。配对及解除事件带 `event_id`，设备回执前不显示为“仪器已确认”。`capture_id` 的状态独立持久化：待接单、录制中、待上传、上传中、已保存电脑、留在仪器、失败。当前设备最多一个录制；同一设备可同时有一个后台上传，其他视频排队。接收文件时先校验长度、MP4 结构和 SHA-256，再持久化文件与数据库；相同拍摄号、相同哈希返回同一回执，不同哈希返回冲突。仅持久回执允许板端删片。

## 本轮安全边界与核对

现场仅使用一台电脑与设置密码的专用局域网。当前 UDP 发现可引导板端改变上传目标，HTTP 设备号没有密码学身份校验，视频走未加密 HTTP；路由器密码不消除这些风险。本轮不做设备验签或 TLS，不能宣称已满足敏感数据传输安全要求。使用前核对路由器客户端隔离、接入设备、电脑防火墙与本机数据权限；后续单列设备身份、密钥交换及加密传输方案。

验收：多校同学号、重名、迁移中断重试、跨天跳过、断开时上传收尾、重复文件回执、匿名文件名、有尺/无尺/模糊帧、Windows Release 中数据库及模型依赖均可用。单次构建通过不等于实板验收。
