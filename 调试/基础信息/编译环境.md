# 编译环境

只在这里改路径和发行版名称。实测过程见 `../记录/WSL2_交叉编译环境实测记录.md` 和 `../记录/WSL2_网络修复与调试经验.md`。

| 项 | 值 |
| --- | --- |
| 发行版 | Ubuntu 22.04 |
| WSL 名称 | `Luckfox-Ubuntu-22.04` |
| 安装位置 | `D:\WSL\Luckfox-Ubuntu-22.04\instance` |
| 用户 | `guanjx` |
| 进入 | `wsl.exe -d Luckfox-Ubuntu-22.04` |
| 交叉编译器 | `/home/guanjx/arm-rockchip830-linux-uclibcgnueabihf/bin/arm-rockchip830-linux-uclibcgnueabihf-gcc` |
| 目标解释器 | `/lib/ld-uClibc.so.0` |
| 未使用 | 完整 SDK 编译；原有 Ubuntu 24.04 保持不动 |

```text
wsl.exe -d Luckfox-Ubuntu-22.04
cd ~
./arm-rockchip830-linux-uclibcgnueabihf/bin/arm-rockchip830-linux-uclibcgnueabihf-gcc -Wall -Wextra -O2 hello.c -o hello-pico-zero
```

网络：`C:\Users\31186\.wslconfig` 中 `[wsl2] networkingMode=mirrored`。Windows 代理是 `127.0.0.1:7897`。拉 Luckfox 源码用 WSL 里的 GitHub；Gitee 在 WSL 中没有凭据。

现成固件加用户态交叉编译即可。只有现成固件缺驱动或 ISP 能力时，才需要完整 SDK。
