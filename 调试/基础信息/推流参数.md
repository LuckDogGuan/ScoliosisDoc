# 推流参数

推流只用来测试摆放和焦距。断线、重连以后再处理。正式结果是录像文件上传到电脑，拍摄文件参数在 [软件框架](../软件架构/Pico_Zero_拍摄仪器软件框架设计.md)。

只在这里改推流测试要用的数字。各档跑了多久、怎么套用，见 `../配置/方案.md`。

当前板上是画质优先、并且这次连续最久的一档：`rkipc.ini.10fps-640kbps.ini`。10 fps、640 kb/s，每帧约 8 KB。Wi-Fi 连续拉满 6 分钟，结束时网关 ping 仍通。15 fps / 512 kb/s 的 VLC 只到 4 分 42 秒，而且每帧大约少一半。

输出帧率用 `60/6`。不要改成 `10/1`，整数路径不会按传感器的 60 fps 丢帧。

| 键 | 当前值 | 作用 |
| --- | --- | --- |
| `isp.0.adjustment:fps` | 60 | 传感器实际帧率 |
| `video.0:src_frame_rate` | 60/1 | 与传感器一致 |
| `video.0:dst_frame_rate` | 60/6 | 编码器输出 10 fps |
| `video.0:width` / `height` | 1280 / 1080 | |
| `video.0:output_data_type` | H.265 | |
| `video.0:rc_mode` | CBR | |
| `video.0:max_rate` | 640 | 单位 kb/s |
| `video.0:gop` | 10 | 10 fps 下约 1 秒一个 I 帧 |
| `video.0:stream_smooth` | 100 | 减少码率突发 |
| `video.0:enable_motion_deblur` | 0 | |

套用：

```powershell
powershell -File "D:\code\Scoliosis\Luckfox\调试\工具\套用推流方案.ps1" -Name "rkipc.ini.10fps-640kbps.ini"
```

Wi-Fi 省电由脚本关掉，重启后要再套用一次。预览用 RTSP over TCP：

```text
rtsp://192.168.0.66:554/live/0
```

内核日志应出现 `fps fix [60/1] -> fix [60/6]` 和 `bps [600000:640000:680000]`。
