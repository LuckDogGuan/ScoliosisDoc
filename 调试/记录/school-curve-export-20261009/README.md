# 本校汇总、详情与曲线导出 — 2026-10-09

用户要求：先总览导出人数、各年级／班级及男女人数，再详细信息，前后顺序一致；导出完整曲线而非逐帧图片；必须选择学校才能导出；记录页明确显示最大尺读数。

Flutter3.3.4代码提交5852c50。两页未选学校的导出按钮禁用，操作入口再次校验。记录Excel生成器拒绝空学校及跨学校数据。男女仍始终导出，其他筛选生效。

名单保留“汇总→本校班级男女详情”布局，男女工作表顺序随选定男先／女先一致。记录先“导出汇总”：本次筛选范围内学生去重人数、男女／未知性别、记录数、年级及班级统计；之后拍摄汇总、角度明细、尺读数曲线与曲线数据。同一份有序记录贯穿所有工作表，年级班级升序、班内按所选男女及记录排序。

每段真实视频一条原生、可编辑Excel曲线，以视频时间秒为横轴、带符号尺读数为纵轴，直线连接，不平滑，缺失读数断线。不嵌入逐帧图片，历史测试图不混入真实曲线。没有有效真实读数的记录显示无法绘图的原因，不制造角度。图表采用[微软公开的ScatterChart格式](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.charts.scatterchart?view=openxml-3.0.1)。

记录页最大绝对尺读数显示两位小数及°，缺失时显示“未分析／分析中／分析失败／无有效读数／历史测试图（非实测）”。Excel最大读数为数字，旁边增加原因说明。
