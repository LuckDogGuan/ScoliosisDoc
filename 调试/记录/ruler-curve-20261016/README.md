## 曲线规则

- 保持每 2 帧计算一次、原帧号与真实时间戳；显示角度范围固定为 −10°～+10°，包含两个端点和真实 0°。
- 超过范围的原始读数保留在数据库中，界面、统计和导出中不作为有效角度，也不会用其他值补回该点。
- 连续缺失 1～2 个采样点：前后都有有效读数时，按真实时间插值；在开头或结尾仅有一侧有效读数时，沿用最近的有效值。等时间戳时取两侧平均。
- 连续缺失 3 个及以上不补；整段没有有效读数时也不补。
- 插补只生成曲线展示数据。空心点和悬停文字“估算”明确区分补点；原始角度、失败原因、有效率和最大角度不由补点改写。Excel 保留原始缺口，不导出估算值。
- 曲线以有界三次曲线连接各点，控制点限制在相邻读数范围内，避免绘制出超量程或虚假的额外峰值；长缺口仍断开。

这提高的是展示连续性，不是模型识别准确度。若要真正改善 ±10°附近的拒读，需增加端点附近具有可靠人工角度的清晰样本后再训练和留出验证。本轮没有扩大量程、重新训练或改变 C DLL/模型。
