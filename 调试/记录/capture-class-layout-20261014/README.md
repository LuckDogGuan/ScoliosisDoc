# 3.3.12 拍摄节奏、班级导出与侧栏改版记录

日期：2026-10-14。工作空间的学校、年级和班级由本轮导入固定；不跨工作空间合并，也不实现升学/换班迁移。

## 已实现

- 背光保持双键500ms点亮、松键后1000ms关闭。内部800ms提前预留语音交接，1000ms仅播一次“开始拍摄”，最早1200ms请求开录；未准备好时延后，语音不阻塞录像。晚到准备也先完成交接。预告取消/许可失效要求重新松键；正常完成后松键不会切掉结束或失败提示。
- 正常语音只保留电脑姓名、整批统计，以及仪器开始/完成/失败/过短。上传、连接和许可状态用界面展示；交接间隔200ms，开始提示取消正在播和待播的姓名。两端原有不同声线保留。
- 最终duration_ms沿用仪器录制worker结果；电脑上轮摘要和导出都显示0.1秒精度。上传后临时时长丢失时读取持久完成事件，缺失不补零。实时计时仍允许通信延迟。
- 导出仅显示汇总和各班结果页，后台绘图源只有时间/角度两列并veryHidden。每班名单后3图一排连续向下，无人工分页；序号/学号/姓名/拍摄时间对应。横纵轴同班统一、保留符号和识别失败断点，不平滑或插值。无有效读数显示状态卡，未拍学生没有曲线。
- 班级结果8项：序号、学号、姓名、性别、拍摄时间、录像时长、最大绝对尺读数、结果提示。技术ID、帧、路径、采样数不显示。算法版本仅取本次导出学校记录；旧拍摄固件版本没有数据时标“未记录”。
- 汇总按全校、年级、该年级各班层级排列。名册人数按当前工作空间去重；已拍人数指至少实际开始过，真实失败/过短也属于拍摄尝试，历史测试排除；拍摄次数保留复拍。工作空间原有成功拍摄进度口径没有扩大修改。
- 左上移除重复大图标，侧栏用短标题与仪器状态；工作空间进度常驻。设置内分工作空间/播报/关于，关于含公司信息、实际程序版本与仪器版本，没有查看许可入口。
- Windows版本从原生FLUTTER_VERSION读取；pubspec.yaml为发布版本唯一编辑点。原有tool/verify_windows_delivery.ps1改动原样保留，SHA256为724b1309443fd1cef659707778d54d07ea494b73912231fd0558accde9861ae9。
