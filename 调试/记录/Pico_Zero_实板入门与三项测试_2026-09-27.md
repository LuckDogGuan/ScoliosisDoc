# Pico Zero 实板入门与三项测试（2026-09-27）

后续外置天线、RTC、音量和 Wi‑Fi 对照见[复测记录](./Pico_Zero_外置天线_RTC_音量复测_2026-09-27.md)。

## 先理解这条链

```text
USB → ADB 管理板子
ISG1321 → MIPI/ISP → rkipc → RTSP 实时预览 → 路由器 → 电脑
喇叭 ← ALSA 声卡 ← 板上程序
后续：按键 → 原生 JPEG 抓拍 → 板上暂存 → Wi‑Fi 传电脑 → 电脑确认
```

预览视频和独立照片是两条功能：从 RTSP 提取一帧只用于本次验证，**不是最终要保存的原生照片**。先熟悉 ADB、传感器识别、推流、Wi‑Fi、声音，再做按键和照片上传。

## 本次实测

| 项目 | 证据与结果 |

## 当前固件和待完成的验证

- 板上是出厂测试系统。`/RkLunch.sh` 注释了 `rkipc` 自启动，改为启动一个板上不存在的 `/usr/bin/camera_test`；因此重启后 RTSP 不会自动恢复。本次只手动启动现有 `rkipc`，**没有烧录或修改固件**。
- Windows USB RNDIS 网卡只有 `169.254.*` 地址；按官方教程设置 `172.32.0.100/16` 时，当前 Windows 会话返回“拒绝访问”（缺管理员权限）。已用 `adb forward tcp:8554 tcp:554` 完成 USB 预览测试，并用 Wi‑Fi 完成局域网测试。
- `/userdata/image.bmp` 是固件内置旧文件，不算实拍。原生 JPEG 已通过板上生成和 ADB 取回验证；**按键触发、Wi‑Fi 传图、照片质量**尚未验收。测试后 `rkipc.ini` 已恢复原值（`enable_jpeg=0`、60 fps）。
- 联网前板上时钟为 2021 年；联网后画面显示 2026-09-27，但板上 Unix 时间比 Windows 快约 8 小时。拍摄记录应以电脑接收时间为准，校时与时区仍需修复。
- 用户已调镜头。先前电脑屏幕图有反光和斜拍；随后实拍印刷资料页，标题能读，细字仍软，纸张倾斜、环境强光。是否满足背部采集需按实际工作距离和照明再验收；先统一距离、照明、站姿与参考标记，保持原图并记录采集条件。
- `/userdata` 实际可用空间约 228 MB，原生照片应尽快传到电脑并确认，不能把板上空间当长期图库。
- 多次重启 `rkipc` 后曾出现 MIPI CSI CRC/ECC 报错、RTSP 已连接却无新帧；板卡重启后 ISG1321 重新出图。若再复现，先检查供电和排线固定，**断电后**才能重插排线。重启后板上时间又回到 2021 年，原生 JPEG 文件名也变成 `20210101...`；电脑接收时间必须单独记录。

## VLC 二次连接失败：定位过程

```text
VLC 无法连接 192.168.0.66:554
  → 板上 554 仍监听、USB RTSP 正常
  → Wi‑Fi 显示已关联，但板子连网关 ARP/ping 失败
  → 重新关联后短暂恢复；无 Wi‑Fi 视频时约 50 秒可达
  → Wi‑Fi 拉流后再次失联；降到 15 fps / 约 1 Mb/s 仍复现
```

这说明故障位于板卡到路由器的无线数据链路附近，**不是 VLC 地址写错，也不能仅凭“已连接”判断可用**。目前板子距路由器约 5 米、无明显遮挡；由于 USB 线长限制，暂未完成 1 米近距离对照。关闭 Wi‑Fi 省电未直接恢复，重新关联只短暂恢复。路由器当前是 WPA2‑PSK、单播 CCMP、组播 TKIP；是否与驱动兼容有关尚无证据。现有路由器暂不能管理，后续用可管理的专用 2.4 GHz 路由器做 WPA2‑AES、近距离、持续传图对照；如仍复现，再检查外接天线/驱动。当前调焦与拍照优先走 USB ADB。

## 常用复核命令

在 Windows PowerShell：

```powershell
adb devices -l
adb -s 3253c006806f5194 shell "cat /proc/device-tree/model; wpa_cli -i wlan0 status | grep -E 'ssid|wpa_state'; iw dev wlan0 link"
adb -s 3253c006806f5194 shell "pidof rkipc; cat /proc/asound/cards"
# USB 虚拟网卡未配置时，可临时用 ADB 端口转发：
adb -s 3253c006806f5194 forward tcp:8554 tcp:554
# VLC 打开 rtsp://127.0.0.1:8554/live/0；选 RTSP over TCP、网络缓存 500 ms
# 本次预览只看画面，VLC 关闭音频；不要加 --no-playlist-autostart
```

本次已在电脑上以 `--rtsp-tcp --network-caching=500 --no-audio` 打开 VLC，并确认与本机 8554 端口建立连接；用户确认有画面。若重启板卡，需要先手动启动 `rkipc`，再设置 ADB 转发；恢复画面时也可重新打开 VLC。最后复核：`rkipc` 运行、VLC 已建立 USB 连接、`enable_jpeg=0`、`enable_cycle_snapshot=0`、60 fps、未继续产生周期照片。Wi‑Fi 不稳定阶段优先使用上述 USB 地址。
