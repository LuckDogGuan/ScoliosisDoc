## 医学参数与算法边界

1. **尺读数**：当前三个模型读取尺面、滚珠、数字刻度，输出带正负号的物理尺读数；筛选取同一记录所有有效真实采样的`max(abs(angle_deg))`。这是数值筛选，瞬时识别偏差仍需人工复核。
2. **ATR/躯干旋转角**：侧弯测量尺在正确前屈检查下的指标，SRS所述转诊参考为5°–7°。5°与7°代表不同筛查门槛，不表示轻/中/重侧弯分类。当前设备未完成临床校准，界面保守称“尺读数”。来源：[USPSTF证据说明](https://www.uspreventiveservicestaskforce.org/uspstf/document/evidence-summary/adolescent-idiopathic-scoliosis-screening)、[SRS质量与安全说明](https://www.srs.org/Education/Quality-and-Safety-Library)。
3. **Cobb角**：脊柱X光按椎体终板等方法测量；SRS将X光大于10°作为侧弯定义。不能由本软件视频尺读数换算，也不能把10°筛选选项当成Cobb诊断线。来源：[SRS诊断说明](https://www.srs.org/Patients/Diagnosis-And-Treatment/Diagnosing-Scoliosis)、[SRS侧弯说明](https://www.srs.org/Patients/Conditions/Scoliosis)。
4. 原尺读数算法保留已有**4.55°–5°吸附至±5°**规则，本轮没有新增曲线平滑；保留规则不等于证明设备具备临床性能。算法细节见Flutter `thirdPartyLibrary/使用说明.md`。
5. 历史`thirdPartyLibrary-ruler-test-v1`结果仍标记测试来源，不能混入真实视频角度筛选/有效角度进度；可点击“用原视频重新计算”。重算替换该记录角度样本，操作前备份工作空间数据库。

## 中键状态表

| 状态 | 灯态 | 触发与优先级 |
|---|---|---|
| 故障 | 快闪，亮灭各125ms | 按键读取失败或Wi-Fi needs_attention；最高优先级 |
| 低电预留 | 2秒周期内两次125ms亮脉冲 | 仅预留接口，ADC未接入，运行时不触发 |
| 配对窗口 | 3秒呼吸 | 未配对且窗口打开，45秒超时或手动关闭 |
| 未连接 | 慢闪，亮灭各1秒 | 未配对，或已配对电脑超过15秒未查询；路由器连接不等同电脑在线 |
| 连接正常 | 常亮 | 已配对、15秒内收到来自已配对主机/IP的hello_query |
| 正常关闭 | 熄灭 | SIGTERM等正常退出执行清理；SIGKILL/掉电无法执行用户态清理，不以此承诺冷启动结果 |
