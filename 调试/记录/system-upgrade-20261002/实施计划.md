# 脊柱侧弯上下位机改造计划

## 1. 目标与当前结论

本轮实施第 1–6、8–13 项；第 7 项彩色拍摄暂缓。当前摄像头属于黑白型号，需要更换硬件才能获得真实彩色。[官方说明](https://wiki.luckfox.com/zh/Luckfox-Pico-Zero/CSI-Camera/)

只读检查发现：下位机业务程序早于 Wi-Fi 初始化启动；上位机日志存在约每两秒重复配对确认；SQLite 模块已有代码，但主程序仍读写 CSV、JSON。“两次联网及中间断开播报”尚未完整复现，不能把上述现象直接当作完整根因。本轮没有修改代码或配置。

## 2. 联网、关闭、校时与设备测试

- **启动联网故障：** 补充网络状态、重连动作和语音播放的关联日志，建立能捕捉原始症状的冷启动验收。区分首次连接与连接后故障，避免 Wi-Fi 尚未初始化就触发故障重连；修复上位机重复配对确认的触发条件。真实断线后的恢复和提示继续有效。
- **关闭软件：** 保留关闭确认及拍摄未收尾时禁止退出的规则。确认退出后停止自动配对、查询和上传授权，先持久保存解绑任务，再对本电脑已配对的所有仪器发送解绑。在线仪器等待确认；离线或超时仪器保存“待解绑”，允许退出，下次联系时优先解绑。保留设备历史、名单和视频。
- **自动校时：** 新增 V3 `time_sync` 能力，在首次连接成功、离线恢复及设备重启后的连接成功时，各同步一次电脑 UTC 时间并写 RTC。录制或收尾期间延后执行；录制时长和许可继续使用单调时钟，已有记录时间保持原值。
- **启动网卡设置：** 每次启动检测一次网关为 `192.168.101.1` 的以太网 IPv4 接口，指定该接口探测外网。可联网时启用自动跃点；探测失败时设置 60，并记录结果。没有唯一匹配接口时提示并跳过。仅需要变更时启动提权辅助进程，拒绝授权后提示并继续运行；设置后读回核对，不持续监控。[微软接口及权限说明](https://learn.microsoft.com/en-us/windows/win32/api/netioapi/nf-netioapi-setipinterfaceentry)
- **设备测试：** 已配对、在线且拍摄许可关闭、设备空闲时显示“设备测试”。面板提供左、中、右键实时状态、摄像头画面和喇叭试听。新增诊断开始、续期、状态、结束指令；检测期间屏蔽正常按键业务，关闭面板、断线或租约失效后恢复，须确认全部松键后才接受正常操作。
- **摄像头预览：** 启用 RKiPC JPEG 通道，关闭周期拍照；每秒最多请求一帧，确认文件写完后通过独立 `/api/v3/diagnostics/frame` 接口发送。电脑只显示最新图片，限制单帧大小、不积压、不产生学生记录。仅清理本次检测生成的明确临时文件。

## 3. 名单、拍摄与记录界面

- **男女打印：** 增加“合并打印／男女分开打印”，默认合并。分开时，每班生成男生、女生两个工作表，各设置一页 A4 打印；没有学生的性别不生成空表。保留汇总表，各明细表显示学校、年级、班级和表头，组内沿用选定名单顺序。
- **统一下拉框：** 名单、拍摄、记录页使用下拉控件展示名单排序、性别筛选和性别分组。沿用导入顺序、学号升序、姓名拼音，以及全部／男／女、不分组／男先／女先。记录页的操作不改变当前拍摄任务。
- **拍摄模式：** 将顺序／单独模式放在筛选栏上方独立展示，按钮高度至少 48 像素，放大文字和图标，并明确区分选中背景。顺序模式在初始化、切换模式或空闲时改变范围及排序后，选择首位资料完整、未拍且未跳过的学生；没有待拍人时留空。进入单独模式清空选择，由用户手动选人。已有准备、录制和收尾任务继续保持原归属。
- **记录筛选：** 补齐性别、名单排序和分组，增加日期区间与最新／最早在前，默认最新在前。日期范围包含首尾两天。拍摄时间使用真实开录时间；列表分两行显示 `yyyy-MM-dd`、`HH:mm:ss`，详情及重拍历史显示完整时间。尚未开录的任务不把准备时间显示成拍摄时间。

## 4. 工作空间与 SQLite

- 首次启动显示目录选择，支持创建空工作空间或打开已有有效工作空间；取消选择时停留在选择页。现有旧数据原样保留，不自动迁移或加载。
- 每个工作空间保存独立的名单、筛查、拍摄记录、学生关联、跳过事件和业务日志；视频保存在该目录内，数据库使用相对路径，便于用户整体移动目录。
- 设备信息、电脑身份、界面设置和上次工作空间路径全局共用，统一保存在用户本地应用目录中的 SQLite。
- 将现有 SQLite 真正接入主流程，完整保存 V3 拍摄、完成事件及上传回执状态。先事务保存学生与 `capture_id` 关联，再下发准备指令；视频完整保存、校验及数据库登记成功后，才能确认接收。CSV、JSON 不再承担新运行的持久业务存储；Excel 作为导入导出文件。
- 顶部始终显示工作空间名称、路径、“打开文件夹”和“切换工作空间”。切换前检查拍摄状态、待传视频及未完成接收回执；未全部完成时阻止切换并显示数量。
- 允许切换后，关闭数据库并按关闭规则解除配对，重启进程加载目标目录。新空间不存在的学校、班级和学生选择自动清空；以后启动默认打开上次空间。

## 5. 验证与交付

- **故障与设备：** 冷启动、路由器未就绪、真实断线恢复、重复连接、正常退出及离线待解绑；确认语音与真实状态对应，退出后不自动恢复配对。验证连接校时、录制中延后校时及 RTC 恢复。
- **界面与打印：** 验证三页下拉、模式视觉区别、首位待拍选择、单独模式空选择、日期边界及跨年记录。检查混合性别和单一性别班级的 Excel 内容与实际打印预览。
- **数据可靠性：** 两个工作空间反复切换，确认隔离、重启恢复和目录移动有效；验证待传阻止切换、重复完成事件、重复上传、保存失败及异常退出后恢复。
- **诊断：** 实测三个实体键、画面持续更新和喇叭；确认检测中不会拍摄或解绑，退出后没有遗留预览任务，正常录像仍可工作。
- 实施前保存现有未提交改动基线，逐项执行 GitNexus 影响分析。启动、关闭入口当前风险为 **CRITICAL**，须覆盖相关回归流程。固件编辑、构建和 Git 写操作留在 WSL2；运行 Flutter 检查、Windows Debug／Release 与实板验收，交付版本包、哈希、验证记录和回滚说明。旧数据及未传视频保留。
