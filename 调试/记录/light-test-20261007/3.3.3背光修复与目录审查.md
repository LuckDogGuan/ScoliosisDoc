## 原因与行为

3.3.2仅有独立背光测试，没有将GPIO55接入业务按键计时。原待办为拍摄前1秒亮、结束后0.5秒灭；以本轮用户要求为准，改为上位机允许拍摄时左右键按住0.5秒亮，释放任意一个键后1秒灭。拍摄仍按原1.5秒长按开始。

- app/runtime_v3.c：沿用拍摄权限、诊断互斥和解除配对状态。
- middleware/buttons.c：统一500/1000毫秒计时；短按不亮、重新按住取消关闭、读键异常/采样中断/权限失效立即灭。
- platform/light_test.c：GPIO55、中键PWM、资源锁、退出清理；platform/luckfox_gpio.c：按键输入与上拉初始化。
